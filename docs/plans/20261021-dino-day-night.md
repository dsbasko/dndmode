# Смена дня и ночи в стиле `dino`

## Overview
- Стиль `dino` (Linux) сейчас только ночной. Добавляем смену темы как в Chrome: каждые 700 очков ночь плавно (≈ 1 с) сменяется днём и обратно.
- Забег начинается с ночи — щит не вспыхивает белым при блокировке.
- Ночью на небе луна (фаза меняется с каждой ночью) и две звезды; днём они растворяются в фоне.
- Стиль остаётся косметическим: щит непрозрачен, блокировка ввода не меняется.

## Context (from discovery)
- Код стиля: `internal/linux/overlay/dino.go` (модель `dinoRun`, вид `dinoView`, `dinoBake`), `dino_art.go` (палитра `dinoPalette`/`dinoColors`, арт `dinoArt`), `dino_test.go`, `anim_linux.go` (`dinoAnim`).
- Сейчас `images[art]` — по одному запечённому спрайту на арт плюс фон `back`; `frame()` блитит по индексу арта.
- Мигание счёта уже ловит смену `score/100` — смена темы делается тем же приёмом на `score/700`.
- Небо: облака на своём генераторе `cloudRng`, дрейф `speed × dinoCloudSpeed`.
- C перед каждой перерисовкой заливает виджет чёрным; `overlay_fill_rect` уже есть.
- Предыдущий план: `docs/plans/completed/20261021-dino-overlay-style.md`.

## Solution Overview
- **9 заранее запечённых наборов спрайтов** (подход A): шаг `shade` 0 (ночь) … 8 (день), цвета каждого шага — линейная смесь ночной и дневной палитры. `images[shade*dinoSheetN + art]`, `dinoSheetN = dinoArtCount + 1` (последний в наборе — фон 1×1 цвета шага). Кадр берёт спрайты из набора текущего `shade` — переход бесплатный, цвета точные, нового C нет.
- **Луна и звёзды** — обычные спрайты; днём их цвет равен фону, поэтому они растворяются вместе с ночью без отдельной прозрачности.
- **Фон вокруг полосы** днём и на переходе заливается цветом фона шага через `overlay_fill_rect`; ночью его уже залил C.

## Technical Details
- **Палитра** (ночь → день):

  | Символ | Ночь | День |
  |---|---|---|
  | фон | `#000000` | `#F7F7F7` |
  | `a` динозаврик, препятствия, земля, счёт | `#ACACAC` | `#535353` |
  | `g` облака, камешки | `#5F5F5F` | `#DADADA` |
  | `m` луна | `#F0F0F0` | = фон |
  | `s` звёзды | `#DADADA` | = фон |

- `dinoColors` → `dinoNight`/`dinoDay` + `dinoShade(i, shade) dvdRGB` (линейная смесь каналов, `i` — индекс в `dinoPalette`, фон — отдельный `dinoBackground(shade)`).
- `dinoBake(grid, w, h, scale, shade)`.
- **Смена темы**: `dinoRun.day bool` (цель), `dinoRun.shade int`, `dinoRun.shadeWait int`; смена `score/700` (включая переход 99999 → 0) переключает `day` и ставит `shadeWait = dinoShadeSteps (7)`; каждый шаг `shadeWait--`, на нуле `shade` сдвигается к цели на 1 и счётчик снова 7 — ровно 56 шагов от шага смены до `shade = 8`. Старт: `day = false`, `shade = 0`. Порог 700 кратен 100 — смена темы и мигание счёта срабатывают на одном шаге и не мешают друг другу. После 99999 → 0 смена срабатывает и на 99400, и на 0: этот период 600 очков — так и задумано. Ресайз (`layout` → `init`) начинает забег и тему заново, как сейчас со счётом.
- **Луна**: арт 4 фазы по 10×10 (серп, половина, растущая, полная), символ `m`; `y = 20`; при `init` стоит на экране (`x = 0.7 · w`), иначе первая ночь прошла бы почти без луны; дрейф `dinoSkyDrift = 0.25` px/шаг влево независимо от скорости; ушла за левый край — справа (`x = w + dinoSpawnAt`). Фаза: первая ночь — полная; каждое переключение день → ночь — следующая фаза по кругу.
- **Звёзды**: арт 3×3 крестик, символ `s`; ровно 2; при `init` `x` случайно в `[0, w)`, `y` случайно в полосе 10..60; дрейф как у луны; ушла за левый край — справа на новой высоте; генератор — `cloudRng`, в `init` сначала облака, потом звёзды.
- **Индексы арта**: луна (4) и звезда (1) вставляются после `dinoArtCloud`, до земли и цифр — цифры остаются последними.
- **Цвет заливки = фон полосы байт в байт**: `background()` возвращает квантованный цвет (байты запечённого фона шага / 255) — cairo переводит double отбрасыванием дроби, а `bambooARGB` округляет; без квантования на половинных значениях был бы шов в 1 уровень.
- **Заливка в `draw`**: `overlay_fill_rect(cr, 0, 0, boundsW, boundsH, background())` при `shade > 0` — на каждой перерисовке, вне условия `painted`, сразу перед `overlay_canvas_show` (C заливает чёрным перед каждой перерисовкой, и при expose без нового шага иначе остались бы чёрные поля).
- На `shade 4` фон и `a` почти совпадают (≈124 и 128): спрайты на ~0,1 с почти пропадают, как при инверсии в Chrome — посмотреть на превью.
- **Порядок кадра**: фон → звёзды → луна → облака → земля → препятствия → динозаврик → счёт.
- **Без** мерцания звёзд и отдельной анимации появления.
